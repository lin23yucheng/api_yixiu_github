# Public code export

This repository contains sanitized source code and synthetic example identifiers.
It has independent Git history. `GH_exclusive` is the publication branch;
`main` mirrors the same sanitized commit for GitHub's default branch.

## Local configuration

1. Install dependencies with `python -m pip install -r requirements.txt`.
2. Copy `config/env_config.example.ini` to `config/env_config.ini`.
3. Fill in your own service URLs, accounts, passwords, space/device identifiers,
   database settings and task IDs. Both `fat` and `prod` login sections are provided.
   Login values also support `YIXIU_FAT_TOKEN_URL`, `YIXIU_FAT_URL`,
   `YIXIU_FAT_USERNAME`, `YIXIU_FAT_PASSWORD`, `YIXIU_FAT_CLIENT_ID`
   (replace `FAT` with `PROD` for the other environment).
4. Copy `bash/json/config.example.json` to `bash/json/config.json` and
   `bash/json/params_data.example.json` to `bash/json/params_data.json`.
   Supply your own gRPC endpoints and obtain an authorized device token.
5. Place your own TLS files in `bash/crt/` (`ca.crt`, `client.crt`, `client.key`).
   Supply the external gRPC client and authorized test fixtures locally at the
   paths required by each test. They are intentionally excluded from this export.
6. For optional AI analysis, create ignored `config/secret.env` with your own
   `GITHUB_TOKEN` or `APIKEYS_DS`, as referenced by `config/ai_config.ini`.

Real environments, credentials, certificates, business data, executables, images,
archives and generated bytecode are excluded. Example IDs in source code must be
adapted locally before integration tests can run. The sample gRPC client config
is `examples/application-local.example.yml`; its actual loading rules belong to
the external client executable. Local configuration is ignored by Git.

## Updating this repository

Updates must pass through the private allowlisted export tool. Do not merge,
fetch or push private repository history here. The export tool scans for known
private values and credential signatures, checks Python/JSON/INI syntax, and
does not push automatically. New files and new kinds of sensitive content still
require human review. Configure only the GitHub remote in this checkout.
